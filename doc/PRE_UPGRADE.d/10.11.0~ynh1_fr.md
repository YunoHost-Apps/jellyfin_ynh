Bienvenue dans cette nouvelle version 10.11.0 de Jellyfin ! 🎉

Comme il s'agit d'une nouvelle version majeure, certaines choses sont à savoir avant la mise à jour. Merci de lire ce qui suit **attentivement** :

- Pour pouvoir passer à cette nouvelle version, vous devez déjà être en version 10.10.7. Si ce n'est pas le cas, mettez d'abord à jour vers cette version en ligne de commande : `yunohost app upgrade $app -u https://github.com/YunoHost-Apps/jellyfin_ynh/tree/be23267b55c6f2c2caeb23566357d0564fe2f914`
- La première mise à jour inclura PLUSIEURS MIGRATIONS LONGUES, qui peuvent prendre jusqu'à plusieurs heures selon la taille et l'état de votre bibliothèque. N'ANNULEZ PAS ET N'INTERROMPEZ PAS LE SYSTÈME pendant ces migrations ; laissez-les tourner pendant la nuit si possible pour les très grandes bibliothèques.
- Après la mise à jour, il est fortement recommandé de lancer une analyse complète de la bibliothèque afin de s'assurer que toutes les données sont correctement renseignées.
- Jellyfin 10.11.0 n'est PAS compatible avec les systèmes ARM 32 bits (armhf), comme les Raspberry Pi de 1ʳᵉ et 2ᵉ génération ou d'autres SBC anciens ou d'entrée de gamme, ni avec tout système ARM fonctionnant sous un système d'exploitation 32 bits. Vous devez utiliser un système d'exploitation ARM64 pour faire fonctionner Jellyfin 10.11.0 sur ARM.

Pour plus d'informations, nous vous encourageons à lire [l'article de blog de la version de Jellyfin](https://jellyfin.org/posts/jellyfin-release-10.11.0).

Comme toujours, si quelque chose se passe mal, n'oubliez pas de **partager les logs** afin que nous puissions vous aider 🤓
